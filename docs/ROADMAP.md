# FitScan AI – Roadmap

This roadmap outlines the planned phases and features for the project.

---

## Phase 1 – Scaffold & Contracts ✅
- Repo structure, templates, and CI
- Contracts agreed for modules
- Basic Streamlit scaffold

## Phase 2 – Core Features (MVP)
- Pose detection (AI person)
- Exercise logic (Squat counter, pushups, etc.)
- Web frontend integration
- Basic analytics (rep counting vs benchmarks)

## Phase 3 – Enhancements
- Gamification badges
- Expanded analytics dashboard
- Improved UI styling

## Phase 4 – Stretch Goals
- Multi-exercise support
- User accounts / persistence
- Integration with wearables
- Social / leaderboard features

---

📌 This roadmap is flexible — team members should propose changes via Issues and PRs.
